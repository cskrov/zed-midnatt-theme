# Zed Midnatt theme
A dark theme for the Zed editor.

# Installation

## As a dev extension
1. Clone this repository.
2. In Zed, open the Extensions page and click `Install Dev Extension` (or run the `zed: install dev extension` action).
3. Select the cloned repository folder.
4. Select the theme with `theme selector: toggle` and choose `Midnatt`.

## As a local theme
Run `make` or `make update`.
It will copy `themes/midnatt.json` into the Zed theme folder as `~/.config/zed/themes/Midnatt.json`.

# About
The name, "Midnatt", is Norwegian for "midnight".
